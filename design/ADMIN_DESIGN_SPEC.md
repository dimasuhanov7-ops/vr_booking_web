# Дизайн админки — спецификация

Источник: Claude Design canvas «Админка VR.dc.html» (проект
`8d5d5ffe-dca2-44b9-9385-3fac38fbaae5`), обновлённый макет снят **2026-09-08**.
Эталоны: `admin-widget.template.html`, `admin-widget.logic.js` (verbatim с канвы).
Задача агенту: `docs/ADMIN_TASK.md` (ручная расшифровка заказчика — устарела,
расхождения ниже).

> **Статус реализации (2026-09-08).** Презентационный слой Flutter-админки
> (`lib/features/admin/presentation/`) перерисован по этому макету: 4 вкладки,
> сетка «Занятость по часам», drawer карточки брони (просмотр + правка-оверлей),
> drawer «Новая запись» с календарём. Авторизация (Supabase Auth) и реальный
> `AdminRepository` сохранены. Правка и создание броней пока живут только в
> состоянии `AdminBloc` — соответствующих методов записи в `AdminRepository`
> ещё нет (см. §8 п. 7–8).

## 2. Данные прототипа

- **CLUBS**: Effect VR — 1 зал «Зал» (4 VR + 2 PS5), 11:00–22:30, пауза 10 мин.
  V-Ray — «Большой зал» (12 VR, без PS5), «Малый зал» (4 VR + 2 PS5), 11:00–23:00, пауза 0.
  **Без варианта «Весь клуб».**
- **Календарь**: `days()` = 120 дней от `2026-09-03` (для «Новой записи» и ленты дат).
- **Тарифы** (одинаковые у всех залов, редактируются, реактивны): VR-шлем
  **1400 ₽/ч** будни / **1700** выходные; PS5 **1000** / **1200**.
- **Пакеты (7):** те же, что в снимке 2026-09-04 (p1–p7). «по часам» =
  `(rate.vr·vr + rate.ps5·ps5)·dur/60` по будничному тарифу зала — реактивно от вкладки «Цены».

  | id | Клуб | Зал | Название | VR | PS5 | Мин | Цена |
  |---|---|---|---|---|---|---|---|
  | p1 | Effect | Зал | Вдвоём | 2 | 0 | 120 | 5 000 |
  | p2 | Effect | Зал | Компания | 4 | 0 | 120 | 10 000 |
  | p3 | Effect | Зал | Полный зал | 4 | 2 | 120 | 14 000 |
  | p4 | V-Ray | Большой зал | Команда | 6 | 0 | 120 | 14 000 |
  | p5 | V-Ray | Большой зал | Арена | 12 | 0 | 120 | 26 000 |
  | p6 | V-Ray | Малый зал | Малый зал целиком | 4 | 2 | 120 | 14 000 |
  | p7 | V-Ray | Малый зал | Шлемы и PS5 | 2 | 2 | 60 | 4 300 |

- **LOG (16 записей, `day` 0/1/2)** — основной датасет вкладки «Записи». Поля:
  `club, hall, day, time, dur, vr, ps5, name, phone, pack, status, src` (`виджет`/`звонок`),
  плюс у части — `prepay` (₽) и `note` (текст для карточки). Несколько записей в один час
  того же зала — чтобы сетка занятости показывала параллельные брони разными цветами.
- **SEED (5 записей)** — старый датасет вкладки «Брони». Вкладки в UI больше нет,
  но `bookings*` vals остались в логике. **Не использовать.**
- **`state.created`** — брони, созданные через «＋ Новая запись» (`src: "админка"`).
- **`state.edits`** — правки существующих записей (`{ [id]: { поле: значение } }`),
  накладываются поверх LOG/created спредом. `state.cancelled` — id отменённых.

## 3. Каркас страницы

1. **Закреплённая шапка** (вне скролла — `Column([header, Expanded(scroll)])`,
   maxWidth 1400, паддинг 20): слева eyebrow «АДМИНКА» + «бронирование Effect VR / V-Ray»;
   справа — табы клубов + «Выйти». Клуб переключается с любой позиции прокрутки.
2. **Ряд таб-бара** (внутри скролла): табы `Цены · Пакеты · Доступность · Записи`

3. Контент вкладки (внутри скролла).

## 4. Вкладки

### 4.1 Цены (`isPrices`)
Грид карточек `repeat(auto-fit, minmax(300px, 1fr))`. Карточка зала: заголовок = имя зала,
справа `meta` = имя клуба; `hint` = «N шлемов [и M PS5]». Сетка
`minmax(0,1fr) 88px 88px` — строка на VR и (если есть) PS5, два инпута (будни/выходные,
right-aligned, tabular-nums). Подпись «Выходные — суббота и воскресенье. Значения в рублях за час.»
Ниже — панель **«Расчёт длительности»**: плашки 1 ч / 2 ч / 3 ч, цена = `wd.vr·N/60·60`,
подпись «выходные — …».

### 4.2 Пакеты (`isPacks`)
Описание + `packsHint` (состав залов). Строка пакета (`rowStyle`, flex-wrap):
слева имя + `meta` («Зал · N шлемов [+ M PS5] · K ч») + `compare`
(«по часам вышло бы X ₽» акцентом, если пакет дешевле; иначе «дороже почасовой на …» /
«равно почасовой цене») + красная `note` «Не вмещается: в зале …» если `vr>helmets`/`ps5>ps5`.
Справа — инпуты шлемов/PS5/минут/₽ за пакет + «Выключить/Включить» + «Удалить».
Форма добавления (граница сверху): Название, зал (чипы), шлемов/PS5/минут/цена,
«Добавить» (активна при `name.trim().length > 1`), `newPack.msg` — текстовая ошибка/успех.

### 4.3 Доступность (`isAvail`)
Панель «Приём заявок»: заголовок + `intake.hint` (меняется вкл/выкл) + тумблер.
Список залов (`halls`): имя + `meta` («N мест, доступен» / «скрыт из виджета») +
«Закрыть зал»/«Открыть зал». Панель «Закрыть отдельные слоты»: `slotHint`
(«клуб, часы · перерыв N мин / сеансы подряд»), лента дат `dayChips` (14 дней,
горизонт. скролл), грид `repeat(auto-fill, minmax(96px, 1fr))` слотов
(`slotCells`, час: `t += 60 + gap`), внизу «Закрыть весь день» (жёлтый) / «Открыть весь день».
Ключ слота — `clubId-dayIdx-time`.

### 4.4 Записи

**Отход от канвы (решение заказчика).** Вместо панели фильтров день/зал/тип —
только **выбор дня через календарь-виджет** (`AdminMonthCalendar`). Зал и тип
из UI убраны (`filterHallId`/`filterType` в состоянии остаются, дефолт «все»).
День (`filterDay`) по умолчанию и **после каждого обновления страницы — сегодня
(`0`)**; ручного выбора «все дни» больше нет.

- **2 KPI**: «записей за день» (`live.length` за выбранный день, note «+N отменено»)
  и «сумма» (`Σ rowCost` — цена пакета при точном совпадении состава, иначе «по часам»).
- **Выбор дня** — компактная «таблетка» `AdminDatePicker` (иконка календаря +
  «вт, 8 сентября» + бейдж «сегодня» + шеврон). По тапу — всплывающий календарь
  (`OverlayPortal`, привязан к полю, закрывается по клику вне / после выбора).
  Внутри — тот же `AdminMonthCalendar`, что в drawer «Новая запись» (месячная сетка
  пн-первым, навигация ‹/› в пределах `[сегодня … сегодня+120]`, выходные приглушены).
- **Панель «Занятость по часам»** (по всем залам клуба, день = `filterDay`):
  - Заголовок зала + `cap` («N шлемов и M PS5» / «…, без PS5») + бейдж «загрузка X %»
    (подсвечен при ≥ 60 %).
  - Ряды: шапка времени, по одному ряду на **каждый** шлем («Шлем k») и **каждую**
    PS5 («PS5 k», подпись синяя), внизу «свободно» (число свободных юнитов, красный при 0).
  - Ширина ячейки-часа **тянется на всю доступную ширину** карточки (`LayoutBuilder`),
    минимум 30 px → дальше горизонтальный скролл.
  - Ячейка: цвет брони из HUES (по порядку в дне), в «голове» брони — имя гостя
    отдельным слоем поверх сетки. PS5 — скруглённая капсула.
  - **Hover** по ячейке/легенде (`_HallOccupancy` держит локальный hover-id):
    ячейки наведённой брони — насыщеннее заливка + светлая рамка её цвета
    (`h.text`) и мягкое свечение (`AnimatedContainer`, 200 ms `easeOutCubic`);
    остальные брони плавно приглушаются до .5. Рамка **пер-ячеечная** —
    бронь с разрывом по строкам (VR-блок + PS5-блок, между ними другая бронь)
    подсвечивается только на своих ячейках, без общего прямоугольника.
    Клик — drawer карточки.
  - **Легенда под сеткой**: строка на бронь — цветной чип + «Имя · 12:00–14:00 · 6 шлемов + 1 PS5»,
    кликабельна, участвует в hover. Пусто → «На этот день записей в зале нет.»
  - Общая легенда: «цвет = отдельная запись» / «PS5 — скруглённая капсула» / «свободно».
- Подпись внизу: «Нажмите на любую запись в сетке или в подписи под ней — откроется карточка брони.»

## 5. Drawer «Карточка брони» (`detail`)

Слайд справа (`max-width: min(560px,100%)`, `recIn`). Открывается `openRec = <id>`.
Клик по подложке / «×» / `detail.onClose` — закрыть (сбрасывает `timeText`).

- Шапка: имя (22/800) + телефон.
- Чипы (`detail.chips`): «отменена» (красный, если `cancelled`) / клуб / зал / «источник: …».
- **Summary** (6 строк, `#0B0D10`, radius 14): Клуб и зал · Дата (+ «выходной/будни тариф»)
  · Сеанс (`hh:mm–hh:mm · N ч`) · Состав · Расчёт («пакет «…»» / «почасовая оплата») · Источник.
- **Money** (3 строки): Стоимость (tint акцента) · Предоплата («нет» жёлтым, если 0) ·
  К оплате на месте (жёлтым, если > 0). `full` = цена пакета при совпадении состава, иначе «по часам».
- Заголовок «РЕДАКТИРОВАНИЕ» + индикатор «изменено, сохранено» (виден при `edits[id]`).
- **Форма** (`detail.form`): Имя · Телефон · Начало (чч:мм — парсится regex
  `^(\d{1,2})[:.\s]?(\d{2})$`, клампится в часы клуба) · Длительность (чипы 1–5 ч) ·
  Шлемов (чипы 0…`helmets`) · PS5 (чипы 0…`ps5`, только если `hasPs5`) ·
  Предоплата ₽ (только цифры) · Комментарий (textarea, 3 строки).
  Правки идут в `state.edits[id]`, не мутируют LOG.
- Кнопки: «Вернуть исходные» (`onReset`, удаляет `edits[id]`; тускла, если правок нет) +
  «Отменить бронь» / «Вернуть бронь» (`onCancel`, тогглит `cancelled`).

## 6. Drawer «Новая запись» (`create`)

Слайд справа, `create.show` = `state.nc != null`. Открытие (`create.onOpen`):
`nc = { hall: hall0, day: 0, time: open, dur: 60, vr: 2, ps5: 0, name, phone, prepay:"", note:"" }`.

- Шапка: «Новая запись» + `sub` («Клуб · 11:00–12:00 · пн, 8 сен»).
- **Календарь** (`create.cal`): месячная сетка `repeat(7,1fr)`, заголовки пн…вс,
  лид-бланки, дни месяца; навигация ‹/› между месяцами (`ncMonth`), выходные приглушены,
  выбранный — обводка акцента. Подпись `picked` («Сегодня, пн, 8 сентября · тариф будней»).
- **Группы** (`create.groups`, чипы): Зал (только если залов > 1) · Длительность (1–5 ч) ·
  Начало сеанса (`open…close-dur`, шаг 60) · «Шлемов · свободно X из Y» · «PS5 · свободно X из Y»
  (если есть PS5). Чипы сверх свободной ёмкости — `chipOff` (зачёркнуты, штриховка, не кликабельны).
  `set()` пересчитывает и клампит `vr/ps5` по `freeUnits(hall, day, time, dur)`.
- **Инпуты** (`create.inputs`): Имя · Телефон · Предоплата ₽ · Комментарий.
- Итог: `totalLabel` («Стоимость · выходной/будни тариф») + `total` (`(pr.vr·vr+pr.ps5·ps5)·dur/60`).
- `create.msg` (жёлтый): «На это время в зале всё занято…» (`noRoom`) или ошибка валидации.
- «Создать запись» (`onSave`): валидирует имя (≥ 2), состав (≥ 1 юнит), свободную ёмкость;
  добавляет `rec` в `state.created` (`src: "админка"`), переключает на вкладку «Записи»,
  ставит `logDay = nc.day`, открывает drawer новой брони. Кнопка серая при `noRoom`.

## 7. Модалка входа (`locked`)

Видна при `!state.authed`. Полноэкранная (`#08090A`), карточка `max-width: 360px`:
eyebrow «АДМИНКА» + «Вход для сотрудников» + «Раздел закрыт. Введите логин и пароль
администратора клуба.» + Логин + Пароль (`type=password`, Enter = `auth.onEnter`) +
`auth.errStyle` («Неверный логин или пароль.») + «Войти».

**Прототип:** логин `admin` / пароль `vr2026`, флаг `localStorage["vr-admin-auth"]="1"`,
«Выйти» его снимает.
**Flutter:** реальный вход — Supabase Auth **email + пароль**
(`admin_login_screen.dart`, `AdminAuthGate`), не логин/пароль. Модалка = референс
раскладки/копирайта. `booking_staff` + `booking_is_staff()` — allowlist сотрудников.
