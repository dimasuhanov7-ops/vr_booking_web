## 2. Структура экрана

Один вертикальный скролл с **progressive disclosure** (не пошаговый мастер с
экранами — блоки просто появляются ниже по мере заполнения):

```
[ липкая шапка: логотип + переключатели Сценарий/Вьюпорт — только прототип ]
[ рамка виджета ]
  Шаг N из 4 · Заголовок · Подсказка
  (плашка конфликта — если есть)
  ── Клубы (карточки: имя, тег, описание, «N мест сразу», состав, часы)
  ── [после выбора клуба] Зал (чипы; combo-зал «Весь клуб» = пунктирный чип на всю ширину)
     Дата (кнопка → календарь месяц-сеткой)
     Длительность (чипы 1ч / 2ч / 3ч)
     Время начала (сетка слотов: время + точки-«сколько свободно» + «N из M»)
  ── [после выбора слота] План зала (ряды станций, «Взять сразу» 2/4/6/8/12/все, легенда)
  ── [после выбора станций] Кто бронирует (Имя, Телефон, «Сколько будет всего»)
     Промокод (инпут + Применить + строка статуса)
     Плашка применённой скидки
  [ липкий нижний бар: контекст + итог₽ (+ старая цена зачёркнута) + CTA ]
[ карточки «Разбор состояний» — только прототип ]
```

Шаги: `1` пока не выбран клуб → `2` пока не выбран слот → `3` пока не выбраны станции → `4`.
Заголовки: «Куда идём играть?» / «Когда и на сколько» / «Кто где стоит» / «Последний шаг».

CTA нижнего бара: `Далее` → (станции есть, контактов нет) `Заполните контакты` → `Забронировать`.

### Состояния плана станции
| Состояние | Рамка | Фон | Текст | Бейдж |
|---|---|---|---|---|
| свободно | 1px `#33333D` | `#191920` | `#C9C9D2` | «свободно» `#7C7C88` |
| занято | 1px `#232329` | штриховка 135° `#17171C`/`#131318` | `#55555F` | зачёркнутое «занято» |
| выбрано | 2px акцент | акцент@0.22 | `#F2F2F5` | «✓ моя» акцент-tint |
| «заняли» (конфликт) | как занято | как занято | — | «заняли» |

## 3. Бизнес-данные из прототипа

| Параметр | Значение в дизайне |
|---|---|
| **Effect VR** | 1 зал «Зал»: 4 VR + 2 PS5, ряды `[4, 2]`. Часы **11:00–22:30**. Пауза между сеансами **10 мин**. |
| **V-Ray** | «Большой зал» 12 VR (ряды `[4,4,4]`), «Малый зал» 4 VR + 2 PS5 (`[4,2]`), **«Весь клуб»** = оба зала вместе (16 VR + 2 PS5). Часы **11:00–23:00**. Пауза **0**. |
| Открытие | 11:00 (`OPEN`) |
| **Длительности** | 60 / 90 / 120 / 180 мин (в UI чипы: **60 / 120 / 180**) |
| Шаг сетки слотов | `duration + gap` (сеансы впритык, НЕ фиксированная 30-мин сетка) |
| **Цены** | VR **700 ₽ / 30 мин**, PS5 **500 ₽ / 30 мин** → `RATE[type] * duration / 30` |
| **Промокоды** | `VRPARTY` −15%, `DR2026` −10% |
| **Автоскидка** | вкл/выкл + порог станций (по умолч. **6**) + процент (по умолч. **10**). Берётся `max(промокод, авто)` |
| Оплата | на месте (наличные/карта). Итог в баре и чеке — справочно |
| Контактные поля | Имя, Телефон (маска `+7 (900) 000-00-00`), «Сколько будет всего, с учётом игроков» |
| Номер брони | `VR-<число>` |
| Готовность к отправке | имя > 1 симв. И телефон > 5 симв. |
