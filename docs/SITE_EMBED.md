# Виджет бронирования на сайтах клубов — памятка для агента, который делает сайт

Файл самодостаточный: его можно отдать целиком, доступ к репозиторию виджета не
нужен. Первоисточник контракта — `docs/EMBED.md` в репозитории виджета,
имена сообщений и параметров ломать нельзя.

## Что это

Онлайн-бронирование VR-клубов **Effect VR** и **V-Ray** (Пермь). Это отдельная
страница (Flutter Web, статические файлы), которая подключается к сайту клуба
через `<iframe>`. Сайту не нужно ходить в базу, считать цены или проверять
занятость — всё это делает сам виджет.

**Один бандл обслуживает оба клуба.** Отдельная сборка под каждый сайт не
нужна и не делается: клуб задаётся параметром в адресе. Обновление виджета
заливается один раз и работает на обоих сайтах.

Адрес виджета: `https://ЗАПОЛНИТЬ/` — подставьте фактический (тот, откуда
раздаются файлы виджета: `index.html`, `main.dart.js`, папка `canvaskit/`).

## Код для вставки

**Сайт Effect VR:**

```html
<iframe id="vr-booking"
        src="https://ЗАПОЛНИТЬ/?club=effect&source=site"
        style="width:100%;max-width:480px;border:0;display:block;margin:0 auto;height:680px"
        title="Онлайн-бронирование Effect VR"></iframe>
<script>
  (function () {
    var frame = document.getElementById('vr-booking');
    var ORIGIN = 'https://ЗАПОЛНИТЬ';   // строго тот же адрес, что в src
    window.addEventListener('message', function (e) {
      if (e.origin !== ORIGIN) return;  // чужие сообщения игнорируем
      var m = e.data || {};
      if (m.type === 'vr-booking:height' && m.height) {
        frame.style.height = m.height + 'px';
      }
      if (m.type === 'vr-booking:success') {
        // цель в Метрике:
        // ym(XXXXXX, 'reachGoal', 'booking', { order: m.orderId, amount: m.amount });
      }
    });
  })();
</script>
```

**Сайт V-Ray:** то же самое, но `?club=vray&source=site` и заголовок
«Онлайн-бронирование V-Ray».

`?club=` фиксирует клуб: выбор клуба не показывается, мастер сокращается с
четырёх шагов до трёх, оформление подстраивается под клуб (Effect — лаймовый,
V-Ray — зелёный). Без этого параметра виджет начинает с вопроса «Куда идём
играть?» и предлагает выбрать клуб — **сейчас на `demo.effectvr.ru/online`
именно так, параметр в адрес вставки не добавлен.**

## Параметры адреса

| Параметр | Значения | Назначение |
|---|---|---|
| `club` | `effect` \| `vray` | Зафиксировать клуб. Неизвестное значение игнорируется. |
| `source` | `site` \| `vk` | Попадает в бронь, видно в статистике, откуда пришёл клиент. |
| `date` | `YYYY-MM-DD` | Предвыбрать дату — удобно для кнопок вроде «Дни рождения». Прошлое и дальше 30 дней игнорируется. |
| `duration` | `60` \| `120` \| `180` \| `240` | Предвыбрать длительность сеанса в минутах. |
| `admin` | `1` | Служебная панель персонала. **Никогда не ставить на сайте и не давать на неё ссылок.** |

## Сообщения виджета странице

Виджет шлёт `postMessage` родительскому окну. Всегда проверяйте `event.origin`.

| Тип | Поля | Когда приходит |
|---|---|---|
| `vr-booking:ready` | — | Виджет загрузился, отрисован первый кадр. |
| `vr-booking:height` | `height` — число, CSS-пиксели | Высота контента изменилась. До загрузки один раз приходит `680`. |
| `vr-booking:step` | `step` — 1..3 (или 1..4 без `?club=`) | Клиент перешёл на следующий шаг. |
| `vr-booking:success` | `orderId`, `club`, `stationCount`, `minutes`, `amount` | Бронь создана — момент для цели в Метрике. |

**Модель прокрутки:** фрейм тянется по содержимому, прокручивает страница-родитель.
Внутреннего скролла у виджета нет — поэтому обязательно подгоняйте высоту по
`vr-booking:height`, иначе фрейм останется 680 пикселей и содержимое обрежется.

Кнопка «Забронировать» не может «прилипать» к низу экрана изнутри фрейма:
виджет не знает о прокрутке родителя. Если нужно, липкость делается на стороне
сайта — обёрткой `<div style="position:sticky;bottom:0">` вокруг фрейма.

## Чего не делать

1. **Не ставить `loading="lazy"` на этот фрейм.** Виджет — главное содержимое
   страницы, отложенная загрузка добавляет несколько секунд ожидания.
2. **Не пропускать файлы виджета через оптимизаторы сайта** (минификация JS/HTML,
   «объединение файлов», отложенная загрузка скриптов в плагинах кэширования
   вроде LiteSpeed Cache или Autoptimize). Это статический бандл Flutter, любая
   переупаковка его ломает. Если виджет лежит на том же хостинге, что и сайт,
   исключите его папку из правил оптимизации.
3. **Не менять файлы внутри бандла** — они перезаписываются при каждом обновлении.
4. **Не подменять `ORIGIN`** на `'*'` в проверке сообщений.
5. **Не встраивать виджет по http** — только https, иначе фрейм не загрузится.

## Требования к хостингу виджета (если он на вашей стороне)

Виджет — движок Flutter, на первый заход браузер качает около 3,3 МБ в сжатом
виде. Повторные заходы берут всё из кэша. Поэтому решают настройки сервера:

1. **Сжатие для `.wasm`, `.js` и шрифтов.** Самое важное: несжатый
   `canvaskit.wasm` — 7,2 МБ вместо 2,2 МБ. Проверка:

   ```
   curl -sI -H "Accept-Encoding: br, gzip" https://ЗАПОЛНИТЬ/canvaskit/chromium/canvaskit.wasm
   ```

   В ответе должен быть `content-encoding: br` или `gzip`.

2. **HTTP/2 или HTTP/3.** Проверка: `curl -sI --http2 https://ЗАПОЛНИТЬ/ | head -1`.

3. **Кэш и MIME.** `canvaskit/*` — на год (`immutable`), `index.html` и
   `main.dart.js` — `no-cache`, тип `.wasm` — `application/wasm`. Всё это уже
   прописано в файле `.htaccess` внутри архива с бандлом: его нужно залить
   вместе с остальными файлами (он скрытый — в FileZilla включите показ
   скрытых файлов).

4. **Заголовок `X-Frame-Options` ставить нельзя** — он запрещает встраивание.
   Ограничение встраивания уже сделано через `frame-ancestors` в `.htaccess`:
   разрешены `effectvr.ru`, `vrayarena.ru`, их поддомены и домены ВК. Если сайт
   будет на другом домене — сообщите, добавим его в список, иначе браузер
   покажет пустой фрейм.

## Что прислать команде виджета

1. Фактический адрес виджета (чем заменить `ЗАПОЛНИТЬ`).
2. Домены страниц, где стоит фрейм, — для списка разрешённых.
3. Вывод двух команд проверки из раздела выше (сжатие и HTTP/2).
