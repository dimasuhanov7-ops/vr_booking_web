# Виджет как VK Mini App

Тот же бандл, что на сайтах: отдельная сборка не нужна. ВК открывает адрес
виджета в своём окне и добавляет к нему `vk_app_id`, `vk_platform`,
`vk_user_id`, `sign` и др.

## Что уже сделано в коде

* **Источник брони.** По `vk_app_id` в адресе виджет ставит `source=vk`
  (`LaunchParams`), брони в админке помечены «источник: ВК».
* **VK Bridge** (`web/vk-bridge.min.js`, MIT, `@vkontakte/vk-bridge` 3.0.2).
  Лежит рядом с виджетом: политика безопасности страницы (`script-src 'self'`)
  чужие скрипты не пускает. Подключается из `web/boot.js` **только** если в
  адресе есть `vk_app_id` — на сайтах не грузится.
* **`VKWebAppInit`** отправляется сразу при старте страницы. Без него
  мобильный ВК держит свою заставку и может посчитать приложение зависшим.
* **`VKWebAppSetViewSettings`** — тёмная панель и статус-бар под цвет виджета
  (на части платформ не поддерживается — ошибка глушится).
* **Имя из профиля** (`VKWebAppGetUserInfo`, разрешений не требует) подставляется
  в поле «Имя». Приложение ждёт ответа не дольше 1,5 с; если ВК не ответил,
  форма открывается пустой. Сохранённый на устройстве клиент (его имя) важнее.
* Встраивание в окно ВК разрешено: `frame-ancestors` содержит `*.vk.com`,
  `*.vk.ru`, `*.vk-apps.com` (`web/_headers`, `web/.htaccess`).

Чего **нет**: телефона из профиля. `VKWebAppGetPhoneNumber` требует отдельного
разрешения от ВК (заявка в настройках приложения) — без него клиент вводит
номер сам, как на сайте. Когда разрешение будет, добавляется рядом с
`VKWebAppGetUserInfo` в `web/boot.js`.

## Как создать приложение (делает владелец сообщества)

На клуб — отдельное приложение, чтобы у каждого сообщества была своя запись и
своя статистика.

1. `vk.com/apps?act=manage` → «Создать приложение» → тип **Mini App**.
2. Название — «Бронирование Effect VR» / «Бронирование V-Ray», иконка 512×512.
3. Раздел «Настройки» → **адрес приложения**:
   * Effect VR: `https://<адрес виджета>/?club=effect`
   * V-Ray: `https://<адрес виджета>/?club=vray`

   Один адрес — и для мобильной, и для полной версии. `source=vk` добавлять не
   нужно: ВК сам добавит `vk_app_id`.
4. Версия — «Тестовая», затем «Опубликовать» (модерация каталога).
5. Прислать разработчику **ID приложения** — нужен, чтобы проверить на
   реальном телефоне.

Показ в сообществе: «Управление» → «Приложения» → добавить своё приложение, оно
появится в меню сообщества. Для кнопки «Записаться» без приложения — см.
`docs/CHANNELS.md` (вариант А).

## Что понадобится для модерации каталога

* Политика конфиденциальности по публичному адресу (черновик — `docs/PRIVACY.md`;
  ссылка задаётся в админке, «Доступность → Онлайн-запись»).
* Описание, иконка и скриншоты.
* Приложение не должно просить оплату внутри ВК: у нас «оплата на месте», это
  подходит.

## Как проверять

1. Тестовая версия приложения открывается по ссылке из настроек приложения
   только у администраторов. На телефоне — через мобильное приложение ВК.
2. Проверить: заставка ВК пропала сразу после загрузки, имя в форме подставлено,
   бронь создаётся, в админке источник «ВК».
3. Локально (без ВК): открыть виджет с `?vk_app_id=1` — подключается мост,
   запрос профиля остаётся без ответа, форма открывается через 1,5 с.

## Известные ограничения

* Ссылка на политику открывается в новой вкладке — внутри ВК на части
  платформ это покидает приложение.
* Параметры запуска `sign` и `vk_user_id` мы **не проверяем и не сохраняем**:
  брони по-прежнему подтверждаются только телефоном, как на сайте.
